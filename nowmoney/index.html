서비스 소개

NOW MONEY는 여행자 및 해외 결제를 자주 이용하는 분들을 위한 실시간 환율 계산 앱입니다. 개발사 DragonPark(이하 "당사")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」, 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 및 Google Play 개발자 정책을 준수합니다.

본 방침은 NOW MONEY 앱(Android/iOS)을 이용하는 모든 이용자에게 적용됩니다.

✅ 핵심 요약: NOW MONEY는 이용자의 개인정보를 수집하지 않습니다. 앱은 오직 환율 조회와 계산 기능만 제공하며, 회원가입·로그인이 필요 없습니다.

3

수집하지 않는 정보

당사는 다음 정보를 수집·저장·처리하지 않습니다.

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보 (GPS, IP 기반 위치 포함)
  • 기기 고유 식별자 (IMEI, 광고 ID 등)
  • 연락처, 카메라, 마이크 데이터
  • 계좌번호, 카드번호 등 금융 정보
  • 브라우징 이력, 앱 사용 패턴
  • 푸시 알림 토큰 (알림 기능 미제공)
  • 사용자가 입력한 금액 수치 (계산 후 보관 없음)
✅ NOW MONEY는 회원가입·로그인 기능이 없으므로, 계정 관련 어떠한 정보도 수집하지 않습니다.

제공 기관ExchangeRate-API Ltd.

6

로컬 데이터 저장

앱은 기기 내 로컬 저장소(AsyncStorage)만을 사용합니다. 저장된 데이터는 인터넷이나 외부 서버로 전송되지 않으며, 앱 삭제 시 함께 삭제됩니다.

저장 데이터 삭제 방법

  • Android: 설정 → 앱 → NOW MONEY → 저장공간 → 데이터 지우기
  • iOS: 앱 삭제 시 모든 로컬 데이터 자동 삭제
7

데이터 보안

  • 앱은 개인정보를 수집하지 않으므로 개인정보 유출 위험이 없습니다.
  • 모든 외부 API 통신은 HTTPS(TLS)로 암호화됩니다.
  • iOS: ITSAppUsesNonExemptEncryption: false — 앱 자체에 별도 암호화 기능 없음 신고 완료.
  • 앱 내 입력 금액은 화면 표시 후 즉시 폐기되며, 어디에도 기록되지 않습니다.
8

아동 이용자 보호

NOW MONEY는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 본 서비스는 COPPA(아동 온라인 개인정보 보호법) 및 대한민국 「개인정보 보호법」 제39조의3를 준수합니다.

만약 14세 미만 아동이 앱을 사용하고 있음을 인지하시면, 아래 문의처로 연락해 주시기 바랍니다.

9

이용자 권리

앱이 개인정보를 수집하지 않으므로, 별도 요청 없이도 이용자의 개인정보는 당사에 존재하지 않습니다. 로컬에 저장된 즐겨찾기 및 캐시 데이터는 이용자가 직접 삭제할 수 있습니다.

로컬 데이터 삭제

  • Android: 설정 → 앱 → NOW MONEY → 저장공간 → 데이터 지우기
  • iOS: 앱 삭제

GDPR / 개인정보 보호법 관련 문의

EU 거주 이용자 및 국내 이용자는 개인정보 관련 문의·열람·정정·삭제 요청을 아래 문의처로 보낼 수 있습니다. 당사는 요청 수령 후 30일 이내 답변 드립니다.

10

방침 변경 안내

본 개인정보처리방침은 법령, 서비스 변경, 또는 보안 강화를 위해 업데이트될 수 있습니다. 변경 시 이 페이지 상단의 "최종 업데이트" 날짜를 갱신하며, 중요한 변경이 있을 경우 앱 업데이트 출시 노트를 통해 안내합니다.

지속적인 앱 이용은 변경된 방침에 동의한 것으로 간주됩니다.
